# Phoenix Waterproofing Services

A premium, high-performance marketing platform and bespoke Content Management System (CMS) custom-designed and engineered for **Phoenix Waterproofing Services** in Bangalore.

Proudly designed, coded, and maintained by **Ghosh Dynamics**.

---

## 🛠️ Corporate Profile

This application serves as the primary digital portal and administration panel for **Phoenix Waterproofing Services**. It features a modern, ultra-responsive layout with dynamic micro-animations, structured business information systems, corporate project galleries, dynamic customer testimonial showcases, and full search engine optimization controls.

## 🚀 Tech Stack & Architecture

Developed from the ground up utilizing clean code conventions and a robust static-first architecture:
* **Core Framework**: React 19 (custom components), TypeScript (type-safe business models), Vite (optimized asset bundler)
* **Styling & Aesthetics**: Tailwind CSS 4 (smooth glassmorphism, modern radial gradients), Lucide React (vector iconography), Framer Motion (delightful micro-animations)
* **Database & CMS**: Google Firebase Firestore (active real-time cloud data structure) with local storage fail-safe bypasses.
* **Forms & Communication**: Web3Forms API (direct corporate email delivery).

## 💻 Local Development

To run the application locally on your workstation, follow these steps:

### Prerequisites
* **Node.js** 18 or higher
* **npm** or similar package manager

### Environment Configuration
Create a `.env` file in the root directory and configure the environment variables:
```env
VITE_WEB3FORMS_ACCESS_KEY="your-web3forms-access-key"
VITE_ADMIN_USER="admin"
VITE_ADMIN_PASS="your-secure-password"
```

### Installation & Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the hot-reloading development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Delivery & Deployment

This application is completely optimized for production distribution and can be easily hosted on modern platforms (e.g., Vercel, Netlify, or self-hosted environments):
1. **Build the assets**:
   ```bash
   npm run build
   ```
2. The generated production assets will be located in the `dist/` directory, optimized and minified.
3. Configure the env variables (`VITE_WEB3FORMS_ACCESS_KEY`, `VITE_ADMIN_USER`, and `VITE_ADMIN_PASS`) on your hosting dashboard.
